# Design System

## Overview
This design system outlines the visual language for the portfolio project. It is built to communicate clearly with high-end aesthetic values.

## Colors
- **Background**: `#FAFAFA`
- **Surface**: `#F5F5F4`
- **Card**: `#FFFFFF`
- **Text Primary**: `#1C1917`
- **Text Secondary**: `#57534E`
- **Text Muted**: `#78716C`
- **Text Placeholder**: `#A8A29E`

## Typography
- **Primary Font (Sans-serif)**: DM Sans (used for body text)
- **Secondary Font (Heading)**: Syne (used for headings, displays, and structural emphasis)

### Line Heights
- **Body**: 165%
- **Headings**: 95% (with -0.03em letter spacing)

## Spacing & Radii
- **Card Radius**: 28px
- **Button Radius**: 999px (Fully rounded)
- **Image Radius**: 28px

## Effects
- **Paper Grain**: The application incorporates a subtle SVG paper grain texture (`bg-grain`) to give it an editorial, tactile feel.
- **Smooth Scrolling**: Lenis is implemented for fluid scrolling physics across the entire interface.
